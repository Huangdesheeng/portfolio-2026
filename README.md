# 卿甜 - 个人作品集网站

## 快速预览

直接双击 `index.html` 文件即可在浏览器中预览网站。

## 安装 Node.js（用于后续 React 开发）

1. 访问 https://nodejs.org/
2. 下载 LTS 版本（推荐 20.x）
3. 安装完成后重启终端

## 运行 React 版本（可选）

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 网站结构

1. **Hero 全屏首页** - 视频背景（网格动画）+ 大标题 + 导航栏
2. **个人经历模块** - 头像占位 + 个人介绍 + 数据统计
3. **精选项目模块** - 大卡片展示作品
4. **个人优势模块** - 6张能力卡片
5. **底部联系方式模块** - 整屏收尾页

## 自定义

- 替换 `index.html` 中的头像占位图为真实照片
- 在 CSS 中修改项目卡片的渐变背景
- 添加真实的项目图片

## 技术栈

- HTML5 + CSS3 + JavaScript
- 暗色系设计
- 响应式布局（适配 PC 端 1700px 版心）
